# SentinelTwin AI

SentinelTwin AI is an enterprise cybersecurity digital twin platform designed to monitor endpoints, collect telemetry, detect threats, and provide AI-powered risk analysis.

## Technology Stack

- FastAPI
- PostgreSQL
- SQLAlchemy 2.0
- Alembic
- JWT Authentication
- Argon2 Password Hashing
